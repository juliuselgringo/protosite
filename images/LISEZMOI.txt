DOSSIER PHOTOS DU SITE
=====================

Option 1 (recommandée) : déposez vos photos directement dans ce dossier.

Dans la feuille Google Sheets, onglet "Produits", colonne "image",
mettez au choix :

    bouquet-roses.jpg            (juste le nom du fichier)
    images/bouquet-roses.jpg     (chemin explicite)

Option 2 : lien Google Drive. Partagez la photo dans Drive
("Tous les utilisateurs disposant du lien", rôle Lecteur), copiez le lien
de partage (https://drive.google.com/file/d/.../view...) et collez-le tel quel
dans la colonne "image" : le site le convertit automatiquement en URL directe
(uc?export=download). Si Google refuse (403 : partage pas encore actif ou quota
Drive temporaire), le site réessaie tout seul via l'URL "thumbnail" de Drive.
Astuce : pour vérifier qu'une photo Drive est bien publique, ouvrez son URL
uc?export=download dans une fenêtre de navigation privée.

Toute autre URL directe (https://...) fonctionne aussi.

Conseils :
- exportez vos photos en JPG compressé, moins de 500 Ko chacune
  (par exemple via https://squoosh.app)
- nommage simple, sans espaces ni accents : bouquet-roses.jpg
- pour publier une nouvelle photo du dossier images/ sur le site :
      git add . && git commit && git push
  (ou bien, sans git : sur github.com, dans le dépôt, "Add file > Upload files")

Les photos d'exemple actuelles viennent d'Unsplash (gratuit) et peuvent
être remplacées par les vôtres.
