DOSSIER PHOTOS DU SITE
=====================

Deux façons de mettre des photos, au choix dans la feuille Google Sheets
(onglet "Produits", colonne "image") :

Option A — lien Google Drive (recommandé pour les photos de téléphone) :
  partagez la photo dans Drive ("Tous les utilisateurs disposant du lien",
  rôle Lecteur), copiez le lien de partage (https://drive.google.com/file/d/.../view...)
  et collez-le tel quel dans la colonne "image".
  => Aucune compression à faire : le site demande à Google une version
     redimensionnée automatiquement (max 1600 px, ~300 Ko au lieu de 3 Mo).
     C'est le fonctionnement normal, il n'y a (quasiment) plus d'erreur 403.
     Si la miniature est refusée, un placeholder gris s'affiche à la place.

Option B — dossier images/ de ce dépôt :
  déposez la photo ici et mettez son nom dans la colonne "image" :
      bouquet-roses.jpg            (ou images/bouquet-roses.jpg)
  Le fichier est servi tel quel (poids d'origine). Pour publier :
      git add . && git commit && git push
  (ou sur github.com, dans le dépôt : "Add file > Upload files").

Toute URL directe (https://...) fonctionne aussi.

Nommage conseillé : simple, sans espaces ni accents (bouquet-roses.jpg).

Astuce : pour vérifier qu'une photo Drive est bien publique, ouvrez son URL
dans une fenêtre de navigation privée.

Les photos d'exemple viennent d'Unsplash (gratuit) ; remplacez-les par les vôtres.
